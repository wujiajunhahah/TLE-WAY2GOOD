## 二、观察目标

**目标 1 · 记录人在不在场时，宠物实际在做什么**
访谈只能拿到"主人以为猫在做什么"，观察拿到的是"猫实际在做什么"。两者的差就是本项目的机会所在。

**目标 2 · 记录主人与宠物互动的发起方**
具体记录：**是谁先动**——人走向猫，还是猫走向人？互动持续多久？谁先结束？

**目标 3 · 记录环境对宠物休息的干扰**
设备位置、声音水平、人员流动，以及宠物被打断的次数与反应。

**目标 4 · 记录现有照看设备的实际布点与盲区**
摄像头装在哪、拍得到什么、**拍不到什么**。

## 三、行为指标表（Field Note Preparation 的核心）

> 本节即课程要求的行为指标（indicators of behavior）。**现场只记录可计数的内容**，解读另写一栏。

### A. 宠物侧（猫）

| 指标 | 怎么记 | 为什么 |
|---|---|---|
| **主动接近人的次数** | 计数 + 时间点 + 对象 | 直接检验"互动由谁发起" |
| **谁先结束互动** | 猫走开 / 人走开 / 被打断 | 判断互动质量 |
| 抓挠行为 | 对象（沙发/爬架/地毯）、持续秒数、次数 | 判断是磨爪需求还是位置偏好 |
| 睡眠位置 | 具体位置 + 是否被移动 | 环境安全感 |
| **被打断次数** | 每次打断的来源（声音/人/其他动物） | 休息质量 |
| 对突发声音的反应 | 竖耳 / 静止 / 躲避 / 无反应 | 判断新设备加声音的风险 |
| 与人保持的距离 | 主动靠近 / 保持 1 米外 / 避开 | 亲近程度 |
| 多猫家庭：两只的距离与互动 | 同处 / 分开 / 冲突 | 资源分配 |

### B. 主人侧（人）

| 指标 | 怎么记 |
|---|---|
| **看向手机 / 监控的次数与时长** | 计数 + 每次秒数（这一条最能出材料） |
| 主动与宠物互动的次数与时长 | 计数 + 秒数 |
| 被工作/他人打断后**是否回到**宠物身边 | 是 / 否 |
| 提到宠物时的话题 | 原话片段 |
| 对宠物行为的解释 | 原话（注意与观察事实分开记） |

### C. 环境侧

| 指标 | 怎么记 |
|---|---|
| 声音水平 | 描述 + 主观分级（安静 / 一般 / 吵） |
| 人流量 | 单位时间经过人次 |
| **设备布点** | 拍照 + 画位置草图 |
| **盲区** | 明确写出摄像头拍不到的地方 |
| 宠物的可及范围 | 能去哪、哪去不了、被什么挡住 |

## 四、三个观察场景

> 课程要求 **3 separate settings（不同时间、不同日期、不同人群）**。每场 **30–40 分钟**即可，写清时间、地点、人群类型。

### Setting 1 · 理发店（商业空间里的猫） **已完成**

| 项 | 内容 |
|---|---|
| 日期/时间 | 2026 年 10 月 5 日下午 |
| 地点 | 受访者经营的理发店（老小区底商） |
| 人群 | 店主 1 人 + 店员 2 人（barber ×1、纹身师 ×1）+ 顾客流动 |
| 目标 | 记录猫在营业环境中的活动、休息与被打断情况 |
| 方法 | 现场观察（在访谈同时进行） |

**已记录内容**：

| # | 观察到的 |
|---|---|
| 1 | 猫用爪子抓沙发（原口述用了"每天"，**观察覆盖天数未记录，暂不量化频率**） |
| 2 | 场所有较多瓶瓶罐罐；**在所见范围内未见猫碰倒物品** |
| 3 | 曾见猫趴在窗口，玻璃门上锁 |
| 4 | 印象是猫不怕人；**具体靠近/躲避行为未记录** |
| 5 | 店内有**一个猫爬架和一张沙发** |
| 6 | 店里**经常放大声的嘻哈音乐** |
| 7 | 音乐**时不时打扰到猫睡觉** |

### Setting 2 · 宠物主人家中（独处环境） **待做（约 40 分钟）**

| 项 | 内容 |
|---|---|
| 计划时间 | 与场景 1 不同日期 |
| 地点 | 任一受访者（Christian / Randy / James 家，或你自己的住处若养猫） |
| 人群 | 独居或白天无人在家的养宠家庭 |
| 目标 | 记录**无人时段**的居家环境布置：猫能去哪、设备装在哪、盲区在哪 |
| 要拿到 | ① 摄像头/喂食器位置与朝向 ② 拍不到的区域 ③ 猫的休息点 ④ 门窗与安全隐患 |

> **不需要等主人全程在场。** 经同意后进去拍环境 + 画一张平面草图就够。

### Setting 3 · 公共空间（陌生环境中的宠物） **待做（约 30 分钟）**

| 项 | 内容 |
|---|---|
| 计划地点 | 宠物医院候诊区 / 宠物店 / 小区遛狗区 / 流浪猫投喂点（任选一处） |
| 人群 | 带宠物外出的主人（与前两场**人群完全不同**） |
| 目标 | 记录宠物在陌生环境中的行为，以及主人如何安抚/管理 |
| 要拿到 | ① 宠物应激表现 ② 主人的安抚动作 ③ 人与宠物的距离变化 ④ 主人是否频繁看手机 |

> **选"宠物医院候诊区"性价比最高**——猫在这种环境里的应激反应最明显，直接关系到"新设备会不会吓到猫"这个设计约束。

## 六、待进一步调查的 10 条洞察

> slides 明确要求 **10 条**。以下是基于现有材料的**待验证线索**（不是结论）。

| # | Insight（待查线索） | 来源 | 怎么验证 |
|---|---|---|---|
| 1 | 猫的休息**已被环境打断**，而主人知情但未处理 | Setting 1 | 追问音乐音量与猫睡眠时段 |
| 2 | 有猫爬架却仍抓沙发 → 可能不是"无处可抓"，而是**位置或材质偏好** | Setting 1 | 记录抓挠位置与爬架位置的距离 |
| 3 | 猫**会主动走向人** → 互动并非全靠人发起 | 访谈 + 观察 | 计数：单位时间内猫主动接近的次数 |
| 4 | 主人对猫行为的解释（"被客人驯化了""不需要陪玩"）与可观察行为**不一致** | Setting 1 | 同一行为分别记录"事实"与"主人解释" |
| 5 | 摄像头同时承担**安全**与**看猫**两种任务，但主人只提其中一种 | 两场访谈 | 追问"装监控最初是为了什么" |
| 6 | 照看链依赖"**顺路**"（工人顺路喂），属搭便车而非承诺 | Interview 5 | 追问不去的那几天谁负责、有无出过问题 |
| 7 | 情感投入者与实际照护者**不是同一个人** | Interview 5 | 追问日常喂食/清理/紧急处置的分工 |
| 8 | 新设备若**发出声音**，是叠加在已嘈杂环境上，不是从零开始 | Setting 1 + 问卷 51.6% | 观察宠物对突发声音的反应 |
| 9 | 主人**查看监控的行为频率**可能远高于他自己陈述的次数 | 待测 | Setting 1/2 计时记录"看向手机"的次数 |
| 10 | 猫在**陌生环境**（医院/宠物店）的应激反应强度，可能决定设备形态 | Setting 3 | 观察并记录应激表现分级 |
