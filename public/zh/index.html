01我们关注的问题

技术让我们看见它，
却没有解决陪伴。

每一天都在发生这样五个时刻。前四步都成立，第五步之后，连接就暂停了。

  1. 01 主人离家 工作 / 出差 / 旅行
  2. 02 想念与担心 “它现在在干嘛？”
  3. 03 打开摄像头 主动去寻找它
  4. 04 单向互动 看它 / 说话 / 投喂
  5. 05 再次断开 关掉设备，关系暂停

关键断点

每一次连接，都要先由你「想起它」才能开始。
而它，没有办法主动找到你。

02现有方案

能看见、能说话、能投喂。
然后呢？

我们看了 5 款代表产品，价格从 $56 到 $199。它们在「监控」和「玩具」两端都做得不错，但都停在同一个地方。

现在已经做到

  • 看见它在做什么
  • 听到你说话
  • 远程投喂或逗它玩
  • 给你片刻安心

仍然缺的是

  • 互动几乎都由主人发起
  • 它无法主动联系你
  • 关掉画面，连接就结束
  • 情感支持是碎片化的

03为谁设计

不是所有养宠人。

而是那些和它关系很深、却经常不在同一个空间的人。

  • 城市上班族白天长时间不在家
  • 频繁出差或短途旅行的人有规律性的分离
  • 独居、与它关系很强的人它是重要的陪伴来源

共同点：它不再只是宠物，是家人。但日常生活让你们没法始终待在同一个空间。

04设计机会

从远程监控，
到远程陪伴。

现在Remote Monitoring

  • 看它在做什么画面告诉你它在哪里，但不知道它怎么想
  • 主人主动说话叫它一声，回应取决于它当时在不在
  • 主人主动投喂或逗它互动由你发起，也由你决定何时结束
  • 互动结束后再次断开关掉画面，连接就停在这一刻

机会Remote Companionship

连接可以从任一侧开始。

  • 让它也能主动靠近从它的自然行为出发，给它一个发起连接的入口
  • 让想念有回应把「我有点想它」变成一次真实的互动
  • 不必一直在线不需要你盯着屏幕，也能给出有意义的回应
  • 从瞬间到关系让陪伴不随着关掉画面而结束

06设计原则

我们要回答的问题

当主人无法陪伴宠物时，
如何让人与宠物之间的情感连接，
依然能自然地发生？

  • 明察Informed用简单、安心的方式知道它好不好
  • 相连Connected即使不在一起，也能感到有意义的双向连接
  • 尊重Respectful顺着它的天性，不打扰它的休息
  • 支持Supportive融进你的生活，而不增加负担

07探索方向

我们正在验证的四件事。

  1. 01它也能主动发起顺着它的自然行为，设计一个能被它触发的连接入口
  2. 02轻量的双向回应不需要你一直盯着屏幕，也不频繁打扰它
  3. 03留下共享的日常不止于实时画面，而是能被回看的片段
  4. 04持续的关系从一次互动，走向长期的情感连接

你可能也想知道

和宠物摄像头有什么不同？

摄像头主要帮你查看、说话和投喂。我们关注的是另外三件事：它能否主动发起连接，你不在线时如何回应，以及一次互动之后连接怎样继续。具体方式仍需要研究和原型验证。
